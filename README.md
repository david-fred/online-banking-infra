# online-banking-infra
Automated infrastructure deployment for a 3-tier high-availability Online Banking System on AWS. Built using Terraform, AWS EKS (Kubernetes), Amazon RDS (MySQL), Nginx Ingress, and ArgoCD for GitOps-driven delivery.
